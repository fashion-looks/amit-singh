# Instagram Reel Studio — @amit_rajput_8001

A lightweight, mobile-first toolkit for planning, editing and measuring original Instagram Reels.

## What this repository tool does
- Turns a Reel idea into a short hook, shot list, caption and CTA.
- Creates a reusable posting checklist and content calendar.
- Tracks views, reach, watch time, likes, comments, shares and saves when the creator enters their own Instagram Insights.
- Generates a review score from the metrics entered; it does not promise virality or guarantee views.
- Uses manually supplied notes and exported Insights. It does not scrape Instagram, collect passwords, auto-follow, auto-like, spam comments or download private media.

## Run it
Open `index.html` in a browser or publish this repository with GitHub Pages.

## Content workflow
1. Choose one clear audience and topic per Reel.
2. Put the most useful or interesting moment in the first seconds.
3. Use original footage, clear audio, captions and a concise story.
4. Add a useful caption and one natural call to action.
5. Review Insights after publishing and learn from retention, shares and saves.

## Important
No tool can make every Reel viral overnight. Recommendations are experiments, not guarantees. Use only footage, music and other material you own or are licensed to use.
