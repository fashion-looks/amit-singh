# AEM Developer Interview & Skills Checklist

Use this as a practice tracker. Be ready to explain trade-offs and demonstrate working examples.

## Java / Maven
- [ ] Explain collections, streams, concurrency and JVM memory basics.
- [ ] Explain Maven modules, dependencies, profiles and lifecycle.

## Sling / OSGi / JCR / Oak
- [ ] Explain Sling request resolution and resource types.
- [ ] Explain OSGi component lifecycle and configuration.
- [ ] Explain JCR nodes, properties, queries and Oak indexing.
- [ ] Explain service users and permission mapping.

## AEM implementation
- [ ] Build and explain a Sling Model.
- [ ] Explain HTL, dialogs, clientlibs and Core Component proxying.
- [ ] Explain Editable Templates and policies.
- [ ] Compare Content Fragments and Experience Fragments.
- [ ] Explain GraphQL and persisted queries.

## Cloud and delivery
- [ ] Explain AEMaaCS architecture and cloud constraints.
- [ ] Explain Dispatcher filters, cache invalidation and rewrites.
- [ ] Explain Cloud Manager build and deployment gates.
- [ ] Describe an AMS/on-prem migration and its risks.

## Engineering quality
- [ ] Demonstrate JUnit/AEM Mocks tests.
- [ ] Explain secure API integration, retries and secret handling.
- [ ] Explain accessibility, SEO and Core Web Vitals improvements.
- [ ] Show pull requests, CI checks and release documentation.

## Behavioral examples
Prepare concise STAR examples for production incident response, performance improvement, migration risk, stakeholder communication and code review.
