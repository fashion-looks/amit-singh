# Security Policy

## Reporting
Please report suspected vulnerabilities privately to the repository maintainers instead of publishing exploit details in a public issue.

## Safe use
- Never commit access tokens, passwords, private keys, or customer personal data.
- Browser task data is stored in local storage on the current device and browser profile.
- This starter kit has no authentication, hosted database, or cloud synchronization.
- GitHub Actions permissions are read-only for repository contents.
- Review any new third-party action or dependency before use.
